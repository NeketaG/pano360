# Проект: iOS-приложение для панорам 360° (передача контекста)

## Цель
Приложение для iPhone, которое снимает сферические панорамы 360° (как Photo Sphere в камере Pixel) и склеивает их само, без видимых швов. Готовых нормальных вариантов в App Store нет (Google Street View из магазина пропал).

## Условия
- Устройство: iPhone 17 Pro.
- Компьютер: только Windows, Мака нет.
- Бюджет: без дополнительных трат. Бесплатный Apple ID и пересборка раз в 7 дней устраивают.
- Работа: в терминале (Claude Code), код пишется на Windows.
- Язык общения: русский, коротко и простыми словами.

## Что уже обсудили
- Xcode работает только на macOS, поэтому нужна сборка вне своего компьютера.
- Варианты: React Native + Expo, PWA, облачный Мак, Flutter. Для этой задачи Expo Go не подходит, нужен доступ к камере и ARKit/CoreMotion на низком уровне (development build или чистый нативный проект).
- PWA не подходит: нет нормального доступа к камере и сенсорам для такой съёмки.

## Как должно работать приложение
1. Экран съёмки ведёт по сетке точек вокруг (как на Pixel): подсказка, куда навести камеру.
2. Каждый кадр сохраняется вместе с ориентацией телефона (гироскоп, ARKit).
3. Кадры проецируются на сферу (equirectangular).
4. Склейка: начальная раскладка по данным гироскопа, потом уточнение по общим точкам (OpenCV), выравнивание яркости, смешивание краёв (multiband blending).
5. Экспорт в стандартный 360-формат (equirectangular JPEG с метаданными), чтобы открывалось в обычных просмотрщиках.

Главная сложность: бесшовная склейка. Интерфейс съёмки проще.

## Открытый вопрос: как собирать бесплатно без Мака
Раньше я сказал, что бесплатного Apple ID хватит для EAS Build. Это нужно проверить: облачная сборка Expo (EAS) для установки на устройство, скорее всего, требует платный аккаунт Apple Developer. Рабочая бесплатная схема, которую стоит проверить первой:

1. Код хранится на GitHub, сборку делает GitHub Actions на macOS-раннере (для публичных репозиториев бесплатно, для приватных есть лимит минут). Результат: неподписанный .ipa.
2. С Windows ставим .ipa на айфон через Sideloadly или AltStore со своим бесплатным Apple ID.
3. Раз в 7 дней приложение нужно переподписывать. AltStore умеет обновлять по Wi-Fi, пока на ПК запущен AltServer, иначе придётся подключать телефон кабелем.
4. Ограничения бесплатного Apple ID: несколько приложений одновременно и лимит на число подписей в неделю. Включить режим разработчика на айфоне.

Нужно проверить актуальные условия (EAS и Apple, Sideloadly/AltStore) перед стартом, они могли измениться.

## План работ
1. Проверить бесплатную схему сборки и установки: пустое приложение на GitHub Actions → .ipa → Sideloadly/AltStore → открывается на айфоне.
2. Прототип: камера, сетка точек, сохранение кадров с углами ориентации.
3. Склейка по данным гироскопа (грубая сфера).
4. Доводка швов: OpenCV, яркость, смешивание краёв.
5. Экспорт в 360-формат и проверка в просмотрщике.

## С чего начать в новой сессии
Первым шагом сделать пункт 1 плана: понять, какой стек даёт рабочую бесплатную сборку (Expo с локальным prebuild или нативный Swift-проект), и подготовить репозиторий с workflow для GitHub Actions.
